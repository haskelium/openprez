# Active deck — canonical source (placeholder)

This is the living, complete source document for the active deck. Slide code in
`presentation/` implements this content. Speaker notes live in each slide's
source (they are concise delivery aids derived from the richer content here) and
appear only in the presenter window.

There is no authored deck yet: `presentation/` ships as the starter deck, whose
single seed slide presents guidance on replacing it (and on browsing the
showcase at `/showcase.html` on the development server). The first
`/opp-propose` seeds this document with the new deck's title and first slide
outline; afterwards it is the delta base for every change.

Changes to this document go through the `/opp-*` commands: see
[openprez/README.md](../README.md). The fork, author, and update lifecycle is
documented in [`docs/starting-your-deck.md`](../../docs/starting-your-deck.md).
